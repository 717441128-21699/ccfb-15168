# 围棋复盘 · 照片棋谱还原

家长用手机每隔几手拍一张棋盘照片，网页自动完成**透视校正 → 交叉点识别（黑/白/空/未知）→ 落子与提子重建 → 漏拍候选 → SGF 导出**，老师在棋盘上校对即可。

## 快速开始

```bash
npm install
npm run dev            # 本地开发，浏览器打开提示的地址
npm run build          # 类型检查 + 生产构建到 dist/
npm test               # 22 个单元/端到端测试
```

样例照片与评估：

```bash
npm run gen:photos -- --out samples --games 4 --width 960 --height 720 --ssaa 2
npm run test:accuracy  # 大规模准确率报告（内存合成，不占磁盘）
npm run test:timing    # 各阶段耗时
npx tsx tools/verify-on-disk.ts --samples samples --limit 40   # 真实 PNG 解码 + 识别
```

## 四个页面

| 路由 | 页面 | 职责 |
| --- | --- | --- |
| `#/games` | 对局列表 | 新建对局（9/13/19 路）、查看、删除 |
| `#/recognize/:id` | 照片识别 | 拖拽/多选导入，逐张 WebGL2 识别，显示后端与耗时 |
| `#/review/:id` | 棋谱校对 | 逐帧核对，点击交叉点改标签，矛盾高亮，漏拍候选点选 |
| `#/export/:id` | 导出 | 终盘预览、SGF 预览/复制/下载，回读校验 |

数据保存在浏览器 IndexedDB（对局、照片元数据、原图 Blob），无后端、无外发。

## 架构

```
src/
  core/                纯 TypeScript，浏览器与 Node 测试共用，零 DOM 依赖
    geometry.ts        单应性矩阵（DLT+高斯消元）、四边形规整、网格映射
    image-buffer.ts    RGBA 缓冲、双线性采样、透视 warp
    detector.ts        Sobel 边缘 + 霍夫直线 → 两组方向外边框 → 交点得四角（含遮挡兜底）
    classifier.ts      交叉点分类（见下）
    rules.ts           围棋规则：落子、提子、自杀判定、串与气
    reconstruction.ts  两帧间 DFS 重建合法落子序列，处理提子/UNKNOWN 通配/漏拍候选
    sgf.ts             SGF(FF4) 序列化与解析、浏览器下载
    pipeline.ts        CPU 参考管线（角点→校正→分类）
  webgl/
    warp-gl.ts         WebGL2 fragment shader 做 GPU 透视校正
    pipeline-gl.ts     门面：优先 WebGL2，失败自动回退 CPU，检测/判定逻辑不变
  synth/               样例照片合成（透视、三灯光、反光、手指、错位、噪点）
  state/               IndexedDB 存储 + 会话编排（逐帧重建）
  ui/                  哈希路由 + 四页面 + 棋盘 SVG 组件
tools/                 照片生成、准确率/计时/磁盘验证工具
tests/                 node:test 单元与端到端测试
```

### 识别管线

1. **角点检测**：图缩到 360px → 模糊 + Sobel → 标准霍夫直线 → 方向聚成两组互相垂直的平行线 → 各取最外侧两条（棋盘外框）→ 线交点得四角。局部遮挡只影响部分边缘，霍夫投票仍能恢复直线；失败时回退边缘包围盒并标低置信度。
2. **透视校正**：输出→源单应性反向采样，把棋盘拉正为正方形。
3. **交叉点分类**（自适应、无写死阈值）：
   - **网格线残留 `gridRemnant`**（最强空点判据）：空交点必有暗网格线穿过内圈，棋子把线切断。实测空点 p10≈19、棋子 p90≈4，阈值 10 落在宽间隔内。
   - **径向边缘对比 `rimContrast`**：沿圆周 24 角度比较圆盘内外灰度跳变，60 百分位压制网格线局部干扰。
   - 灰度三均值聚类区分黑/白；反光靠暗环救回；肤色/低覆盖率判手遮挡 → `UNKNOWN`；高饱和异物 → `UNKNOWN`。
   - 保守的局部中心搜索容忍棋子错位；8 邻域空间投票修正孤立低置信点，但不覆盖 `UNKNOWN`。
4. **落子重建**：相邻两帧做盘面差分，DFS 搜索黑白交替的合法落子序列（自动提子），`UNKNOWN` 作通配点不约束；返回多个带吻合度评分的候选，漏拍时老师点选。

## 指标（实测）

750 张样例、220,950 个交叉点（10 盘残局 × 5 快照 × 3 灯光 × 5 干扰）：

| 干扰类型 | 可见交点准确率 | 遮挡处理率 |
| --- | --- | --- |
| clean | **99.83%** | 100% |
| glare 反光 | **99.60%** | 100% |
| hand 手挡一角 | **99.69%** | 94.8% |
| misplace 棋子错位 | 98.58% | 100% |
| hard 复合干扰 | 98.59% | 94.6% |
| **整体严格准确率** | **99.28%** | — |

三种灯光（暖/中性/冷）下均 ≥99.45%。

**计时**（Node CPU 参考实现，720×540 输入、768 校正图）：p95 全程 **121ms**；浏览器 WebGL2 路径把最重的逐像素 warp 放到 GPU。即便手机 CPU 比开发机慢一个数量级，仍在 2 秒约束内。

### 关于 99.5% 指标的诚实说明

正常拍摄（干净、反光、手挡一角）单张准确率均 **≥99.5%**；专门构造的极端复合干扰（反光+手+错位+高噪点同时出现）和重度错位样本约 98.6%，低于该线。这些点不会被强行猜测，而是标记为 `UNKNOWN` 进入两条安全网：落子重建的规则约束 + 校对页人工裁决。设计取舍是**宁可标未知交人，不输出高置信错误结果**。

## 样例照片怎么造的

`src/synth/scene.ts` 纯 TS 渲染，ground truth 与渲染严格一致：透视四角、木纹值噪声、球面棋子（漫反射+高光+菲涅耳边缘+接触阴影）、三种灯光、高斯镜面反光、胶囊手指（多肤色）、棋子高斯错位、传感器噪点与暗角。`tools/scenarios.ts` 先随机下出带提子的残局，再按灯光 × 干扰展开样本，输出 PNG + 元数据 JSON（含真值标签与遮挡点）。

## 已知边界

- 角点自动检测依赖棋盘外框线可见；完全遮住一条边时走兜底四边形并降置信，建议在 UI 人工拖角修正（当前识别页接受 `knownQuad`，拖拽 UI 为后续项）。
- 重建搜索对单帧间隔的补手上限默认 4 手；间隔过大时候选数会增加，需老师参与。
- 合成照片与真实照片存在域差异，上线前应采集真实棋盘数据复测并据此微调 `classifier.ts` 的自适应阈值。
